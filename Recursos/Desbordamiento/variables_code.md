# Demostración de variables
#### Autor: Jordan

Demostración de los valores que acepta cada tipo de variable.

# Implementación
## C++
```cpp
#include <bits/stdc++.h>

using namespace std;

int main()
{
    ios::sync_with_stdio(0); cin.tie(0);

    int edad = 20;
    long long poblacion = 8200000000;
    double pi = 3.1415926535;
    char inicial = 'C';
    bool aprobado = true;
    string nombre = "Carlos";

    cout << edad << '\n';
    cout << poblacion << '\n';
    cout << pi << '\n';
    cout << inicial << '\n';
    cout << aprobado << '\n';
    cout << nombre << '\n';

    return 0;
}
```
